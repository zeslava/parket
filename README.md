# parket

TUI-просмотрщик для Parquet файлов.

## Установка

```sh
curl -fsSL https://raw.githubusercontent.com/zeslava/parket/main/install.sh | sh
```

Поддерживаемые платформы: Linux x86\_64, macOS Apple Silicon.

Бинарь устанавливается в `~/.local/bin/parket`.

## Сборка

```bash
cargo build --release
```

## Использование

```bash
parket <file.parquet>
```

## Управление

| Клавиша | Действие |
|---------|----------|
| `Tab` | переключить вкладки Data / Schema |
| `↑` / `↓` | скролл строк |
| `←` / `→` | скролл колонок |
| `PgUp` / `PgDn` | скролл страницей |
| `g` | первая строка |
| `G` | последняя строка |
| `/` | поиск — ввести строку, `Enter` применить |
| `Esc` | сбросить фильтр (в режиме поиска — отменить ввод) |
| `q` | выход |

Поиск фильтрует строки по вхождению подстроки в любую ячейку (без учёта регистра). Совпадающие ячейки подсвечиваются.
